# План реализации

| Этап | Работы | Результат |
|---|---|---|
| 0. Аудит | VPS, зависимости, тесты, схема БД, секреты, процессы | План запуска и отката |
| 1. Стабильный бот | Окружение, БД, миграции, systemd, backup, smoke tests | Рабочий бот на VPS |
| 2. API | FastAPI, Telegram initData, сессии, RBAC, health checks | Защищённый backend |
| 3. Mini App MVP | Главная, кандидаты, вакансии, карточки, pipeline, интервью | HR работает из Telegram |
| 4. Админ и 2FA | Роли, филиалы, TOTP, резервные коды, аудит, отзыв сессий | Защищённое администрирование |
| 5. Автоматизация | Уведомления, дедлайны, шаблоны, экспорт, отчёты | Меньше ручной работы |
| 6. Аналитика/AI | Сводки с human review, SLA, источники откликов | Измеримый HR-процесс |
| 7. Hardening | Security review, тест восстановления, нагрузка, runbook | Production-ready релиз |

## Идеи
- MVP: канбан найма, единая карточка, шаблоны по должностям, SLA и просрочки, Security Center, резервный режим уведомлений
- Этап 2: QR-ссылка на вакансию, рефералы, библиотека интервью, аналитика источников, AI-помощник HR, мультиязычность (ru/uz/en/tr), импорт CSV/XLSX
