# Безопасность

## Сделано
- Подпись Telegram initData проверяется на сервере (HMAC) вместе со сроком давности.
- Серверные сессии; в БД хранится только хеш токена; выход отзывает сессию.
- Роль и филиал берутся из сессии, не из запроса. Права проверяются в каждом маршруте.
- Чужие записи отдают 404, а не 403 (защита от перебора ID).
- Журнал действий: вход, выход, создание и смена этапа.
- CORS ограничен доменами из `ALLOWED_ORIGINS`; секреты только в `.env`.

## Не сделано
- 2FA для администраторов (до неё вход защищён только подписью Telegram).
- Ограничение частоты запросов, согласия кандидатов, сроки хранения, шифрование backup.
- Просмотр журнала действий через API.
